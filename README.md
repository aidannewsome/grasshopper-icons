# Grasshopper Icons

The original Grasshopper component icons, drawn by
[David Rutten](https://ieatbugsforbreakfast.com/2012/07/12/on-icons/) and
recovered from the Xara vector sources he published on the
[official guide page](https://developer.rhino3d.com/guides/grasshopper/grasshopper-icons/).
🟡 472/554 identified, 🟡 517/554 exact.

- Download everything: [grasshopper-icons.zip](icons/grasshopper-icons.zip)
- Machine index: [manifest.json](icons/manifest.json)
- Sheet template: [template.svg](icons/template.svg)
- Drawing method: [SKILL.md](SKILL.md)

The recovery is close but not perfect. In the tables below, ✅ marks an
icon whose every construct translated losslessly to SVG. 🟡 marks one that
approximates something SVG cannot express natively (text, conic gradients,
fractal noise), with the reason beside it. David published these sources in
2011, so components added to Grasshopper since then are missing and a few
icons have changed in later versions. If something looks off, or you can
put a name to an unidentified icon, [open an issue](../../issues).
